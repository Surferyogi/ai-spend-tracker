Where these numbers came from

Scanned — receipt emails parsed by the AI Spend Scanner Apps Script and imported as JSON. Each row's source line carries its own receipt or order number.
Manual — charges with no receipt email, e.g. subscription renewals when renewal receipts are switched off. The source line states what the figure rests on.
API consumption — read from the provider console. It is drawdown against prepaid credit, not a payment, and is never counted as spend.
Rule — verified means a receipt or an explicit confirmation exists; assumed means a projection at the last known price. Read the source line before trusting a total.

Monthly scan workflow

The AI Spend Scanner Apps Script runs in each Gmail account on the 1st of the month and emails you a JSON attachment. Save it, then Import below. Import is additive: it matches on receipt number (or date + vendor + amount), adds only what is genuinely new, and never touches an existing row or a verification tick you have set. It shows you exactly what it will add before adding anything.

Backup & reset

Entries live in this browser's localStorage. Clearing site data wipes them — export regularly. The JSON re-imports on any device.
